`WorkshopUpload <путь>` (повтор = апдейт; папку-ключ не переименовывать; на аккаунте ≥ $5).
**Эксперимент `--with-repo`** (перевод экрана выбора кампаний через `data/{mod,nwm}/

Наш айтем загружен (приватный, на авто-проверке). Полностью — в `WORKSHOP.md` (там же
финальные тексты страницы RU/EN). Workshop удобнее `install_ru.py` для раздачи, но
`repository.json` через него под вопросом.

## Модель и метод

Перевод выполнен **Claude Opus** (Anthropic): диалоги — `wf_dialogs.js` с алиасом `opus`;
система/прочее — `wf_batches.js` без override, т.е. модель сессии **Opus 4.8**. Метод:
разговор целиком с контекстом → код-проверка тегов/плейсхолдеров → редакторский проход
(для диалогов). В Workshop помечено тегом `[AI]` (имя модели в публичном описании не
указано — по желанию).

## Авторские права / происхождение (важно)

Официальный русский перевод NWN — **1С** (заброшен ~1.61, база 1.66); народные русификаторы
EE — производные от 1С (ZoG «Wiki Edition» = «1.70 Community» из 1.66 от 1С). У нас фразы
сгенерированы заново с английского (не копия 1С), НО терминология подогнана под привычный
лексикон, извлечённый (`glossary/mined_glossary.tsv`) из 1С-производного ZoG. Поэтому **НЕ
заявляем «1C-copyright free»** и любые правовые гарантии: юридически не заверить; термбаза
тянется из 1С-наследия; сам текст игры — IP Beamdog/WotC (любой перевод — производное). Это
фан-перевод в терпимом Workshop. Максимум — нейтральный факт о методе. Подробности —
`WORKSHOP.md`.

## Доказанная архитектура (не менять без причины)

Переводим **разговор целиком** (LLM видит дерево NPC↔PC) — контекст встроен,
токен-эффективно. Системный текст — батчами по категориям из `2da`.

Двухслойный контроль на каждый чанк:
- **Слой 1 — код (без LLM):** теги/плейсхолдеры (`<...>`, `%s/%d`, `\n` совпадают
  с оригиналом), наличие терминов глоссария, не пусто, нет англ. остатка. Авто-ретрай.
- **Слой 2 — агент-редактор (на диалоги/описания):** смысловой дрейф, нарушения
  глоссария, сломанные теги, тон, непереданная low-INT речь. Адверсариальный промпт,
  отдаёт правки. Мерджим поверх черновика.

Пайплайн: `перевод → код-валидация → редактор → мердж`.

## Терминология — ГИБРИД (зафиксировано)

База = комьюнити-лексикон (`mined_glossary.tsv`, выровнен под D&D 5 Hobby World).
Override до Hobby World только эти (в `hybrid_overrides.tsv`):
- **Fighter → Воин** (не «Боец»), **Ranger → Следопыт** (не «Рейнджер»),
  **Armor Class → Класс защиты** (не «Класс брони»).
Оставлены комьюнити: **Клерик** (не Жрец), **Здоровье** (не Хиты), **Умение** (Feat, не Черта).
Остальные ключевые термины совпадают.

## План полного прогона

1. **2da-классификатор** (`context/` новый скрипт): из `base_2da.bif` достать
   `classes.2da`, `racialtypes.2da`, `feat.2da`, `skills.2da`, `spells.2da`,
   `baseitems.2da`, `des_crft_*`, и т.п. → собрать карту `strref → категория`
   (имя/описание класса/расы/черты/навыка/заклинания/предмета). Формат 2da — текстовый
   (заголовок `2DA V2.0`), но внутри bif; парсить как ресурс (тип 2017) через KEY/BIFF.
2. **Перечисление диалогов:** `base_dialog.bif` (40 `.dlg`) + все `.nwm` в `data/nwm/`
   (`Prelude, Chapter1..4, Chapter1E/2E, XP1-*, XP2-*`). Для каждого — `reconstruct()`
   → уникальные строки + сценарий.
3. **Карта покрытия:** все 112 228 StrRef разнести на: диалоги (из `.dlg`), системные
   (из `2da`), прочее (UI/журнал/misc). Проверить, что ничего не потеряно.
4. **Полный Workflow (батчевый):**
   - диалоги: pipeline по разговорам (`перевод → код-валидация → редактор`);
   - системный текст: батчи по категориям с глоссарием (редактор по желанию);
   - собрать `strref → RU`.
   - **Persistence:** каждый агент-батч пишет свой выход в отдельный файл
     (`translated/<batch>.json`) через Write — НЕ полагаться на возврат значения и НЕ
     делать один агент-Persist на всё (в пилоте он подвёл; данные доставались из
     журналов `subagents/workflows/<run>/agent-*.jsonl`).
5. **Сборка и установка:** writer строит `dialog.tlk` = англ. база с заменой наших
   StrRef→RU, **в CP1251**; затем `install_ru.py` (он же ставит шрифты и чинит repo.json).

## Грабли и уроки (важно)

- **Workflow-скрипт не имеет доступа к ФС** — данные либо в `args`, либо агенты
  (`agentType:'general-purpose'`) читают файлы сами (так и сделано в пилоте).
- **Большие данные в `args` руками не вписать** — пусть агенты читают подготовленный
  JSON с диска по пути из `args`.
- **Workflow → только с явного согласия пользователя** (он его дал на полный прогон).
- **Коммиты — ЧАНКАМИ**, не один монстр на сотни тысяч строк перевода (по кампаниям/
  батчам). Автор — Claude, без трейлеров. Код — англ., доки/README — рус.
- **Веб-проверки:** не задавать WebFetch наводящих вопросов; результаты поиска
  привязывать к нужной игре (app 704450) — общий поиск тащит другие игры.
- **venv для зависимостей**, не `pip --break-system-packages`.
