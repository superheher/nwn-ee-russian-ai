# Терминологическая база для перевода NWN:EE

Подготовка к собственному переводу NWN: Enhanced Edition с английского. Здесь —
глоссарий и термбаза, чтобы перевод был терминологически единым с самого начала.

## Откуда взято

1. **Выровненный двуязычный корпус (главный источник).** Английский `dialog.tlk`
   игры ↔ русский `dialog.tlk_RU.txt` русификатора ZoG/DragonZH. Строка N = StrRef N
   (проверено), поэтому каждая пара — точное соответствие. Этот перевод, по описанию
   авторов, уже выровнен под официальную терминологию **D&D 5 (Hobby World)** — то
   есть корпус де-факто даёт game-точные термины «как в игре».
2. **Сверка с авторитетными источниками (Hobby World / dnd.su).** Ключевые термины
   проверены по [глоссарию dnd.su](https://next.dnd.su/glossary/) и
   [списку классов dnd.su](https://dnd.su/class/), плюс есть официальный
   [«Словарь терминов Hobby World»](https://ru.scribd.com/document/500256650/).

## Файлы

| Файл | Что |
|---|---|
| `mined_glossary.tsv` | **24 640 пар EN→RU** — широкий лексикон из корпуса (заклинания, черты, навыки, предметы, имена). Главный термбанк для перевода. |
| `core_glossary.tsv` | 89 ключевых терминов (характеристики, классы, расы, мировоззрения, спасброски, школы магии, навыки) с категориями и StrRef. |
| `divergences.tsv` | Расхождения «NWN-комьюнити vs Hobby World» — точки терминологического решения. |
| `anchors.txt` | StrRef 0..60 (EN \| RU) — для глаз, видно блоки классов/рас. |
| `mine_glossary.py` | Скрипт-майнер (воспроизводимо пересобирает термбазу из корпуса). |

Пересобрать: `python3 mine_glossary.py <english.tlk> <dialog.tlk_RU.txt> <outdir>`

## Развилка: какая терминология (нужно решение)

NWN — это D&D 3.5e, а Hobby World переводила 5e, поэтому часть терминов расходится.
Проверенные расхождения (полный список — в `divergences.tsv`):

| EN | NWN-комьюнити | Hobby World 5e |
|---|---|---|
| Fighter | Боец | Воин |
| Ranger | Рейнджер | Следопыт |
| Cleric | Клерик | Жрец |
| Armor Class | Класс брони | Класс Защиты |
| Hit Points | Здоровье | Хиты |
| Feat | Умение | Черта |

Из ~23 ключевых терминов расходится ~5–6; остальные (Сила/Ловкость/…, Варвар/Бард/
Паладин/Чародей/Волшебник/Друид/Монах, школы магии) совпадают.

**Три варианта политики:**
- **Комьюнити (рекомендуется):** «Боец/Клерик/Рейнджер/Здоровье». Привычно игрокам
  NWN, соответствует 3.5e-природе игры и уже консистентно с 24k-лексиконом → ноль
  доработки, полная согласованность.
- **Hobby World 5e:** «Воин/Жрец/Следопыт/Хиты/Черта». Официально-современно, но
  термины из другой редакции правил и менее привычны ветеранам NWN; потребует
  переопределить десятки терминов поверх лексикона.
- **Гибрид:** база — комьюнити, точечно поднять отдельные термины до HW по вкусу.

## Как это используется в переводе

При прогоне перевода термбаза подаётся переводчику как **обязательный глоссарий**
(точные соответствия для имён/терминов), а свободный текст (диалоги, описания)
переводится заново. Теги (`<cXXX>`, `<CUSTOM0>`, `%d/%s`) сохраняются байт-в-байт и
проверяются автоматически. Сборка готового `dialog.tlk` — существующим `build_tlk.py`
(CP1251 + наши шрифты + фикс кодировки).
